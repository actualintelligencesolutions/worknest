# AI Guardrails

These guardrails define how humans and AI agents should work in this template.

The project is a disciplined, tenant-aware foundation using:

- React for UI only
- PHP for endpoint contracts, validation, and business logic
- MySQL for persistence only
- DAM for asset lifecycle only

The priority is predictable architecture over clever shortcuts.
